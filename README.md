# Реестр таможенных представителей

Онлайн-справочник по официальному набору открытых данных «Реестр таможенных представителей», ведомому Федеральной таможенной службой (ФТС России).

🌐 Сайт: https://prog815.github.io/customs-representatives/

Справочник бесплатный, без регистрации и установки. Работает прямо в браузере — на компьютере и на телефоне. Данные берутся из официального открытого набора и обновляются автоматически.

---

## Что это за реестр

Это официальный машиночитаемый перечень **юридических лиц, включённых в реестр таможенных представителей** (ФТС России).

**Одна запись здесь — это один таможенный представитель** (одна организация). В текущем снимке справочника содержится **816 организаций** (исходный файл содержит 1080 строк, так как у крупных представителей несколько обособленных подразделений, которые агрегируются в одну карточку).

Каждая запись содержит следующие данные:
- **Реестровый номер** (4 цифры с ведущими нулями, например, `0003`).
- **Дата включения в реестр**.
- **Наименование таможенного представителя**.
- **Юридический адрес**, **телефон** и **электронная почта**.
- **ИНН**, **КПП** (и второй КПП, если есть).
- **Обособленные подразделения** (вложенный список: наименование, адрес и КПП каждого филиала).
- **Ограничения по региону деятельности** и **ограничения по ТН ВЭД** (если применимо, отображаются в служебных данных).

Справочник поможет быстро проверить наличие организации в реестре ФТС, узнать её реквизиты и контакты, а также увидеть полный список её обособленных подразделений (складов, филиалов и т.д.).

---

## Для кого и зачем

- **Участники внешнеэкономической деятельности (ВЭД)** — проверка контрагента перед заключением договора на таможенное декларирование.
- **Логисты и импортёры/экспортёры** — поиск представителя с филиалом в нужном регионе (аэропорту, порту).
- **Юристы, комплаенс и службы безопасности** — оценка рисков и проверка легитимности партнёра.
- **Таможенные брокеры и декларанты** — сверка своих данных и мониторинг конкурентной среды.

## Как пользоваться

### Поиск

Введите в строку поиска одно или несколько слов. Справочник ищет совпадения по:
- наименованию организации;
- реестровому номеру;
- ИНН и КПП;
- контактным данным (телефон, email);
- адресам (как юридическому, так и адресам подразделений);
- названиям обособленных подразделений.

Если ввести несколько слов, система найдёт записи, где встречаются **все** введённые слова (в любом порядке). Регистр букв не важен, а буквы `Ё` и `Е` считаются одинаковыми.

### Фильтры

В интерфейсе **отсутствуют выпадающие списки**. Это сделано намеренно: поля ограничений (регион, ТН ВЭД) в исходном наборе заполнены менее чем у 2% организаций, поэтому фильтры по ним были бы бесполезны. Оставлен только быстрый текстовый поиск.

### Карточка результата

Каждая найденная запись оформлена в виде карточки:
- **Заголовок** — наименование организации.
- **Бейджи** — метка «Таможенный представитель» и реестровый номер.
- **Основные реквизиты** — дата включения в реестр, ИНН, КПП, контакты.
- **Блок «Юридический адрес»**.
- **Блок «Обособленные подразделения»** — если у организации есть филиалы, они выводятся отдельным списком (наименование, адрес, КПП).
- Кнопка **«📤 Поделиться»** — позволяет отправить текстовую карточку со ссылкой на конкретную запись (удобно для отправки коллегам).

> **Примечание:** Уникальный идентификатор записи (ID) не отображается в интерфейсе, но используется для стабильной работы ссылок «Поделиться» (`?code=TAM...`).

### Навигация

- Результаты показываются порциями по 20 штук; кнопка **«Показать ещё»** догружает следующие карточки.
- Счётчик вверху экрана показывает, сколько всего записей найдено и сколько из них уже выведено.
- Плавающие кнопки **↑ / ↓** в правом нижнем углу помогают быстро прокрутить страницу.
- Ссылка **«Очистить»** сбрасывает поисковый запрос.
- При загрузке данных отображается анимированный индикатор. Файл с данными весит около **86 КБ** и загружается за 1–2 секунды.

## Что внутри справочника

В справочнике собраны данные обо всех записях, включённых в текущий снимок набора данных ФТС России. 

Точная статистика по количеству записей и дата актуальности данных всегда показаны **внизу страницы** на самом сайте. Они рассчитываются автоматически на основе загруженных данных.

## Источник и актуальность

- Официальный источник данных — **Портал открытых данных РФ**: [Реестр таможенных представителей](https://data.gov.ru/datasets/39b8888d-a456-4ce1-833a-80a428ee0cf5).
- Владелец набора данных — **ФТС России** ([официальный сайт](https://customs.gov.ru/)).

Данные обновляются из источника автоматически (раз в неделю по понедельникам). Дата актуальности текущей версии видна **внизу страницы**.

## Ограничения и дисклеймер

- Справочник носит исключительно **информационный характер**. Для официального применения (декларирование, юридические заключения) сверяйтесь с действующими государственными реестрами или официальным сайтом ФТС России.
- В исходном наборе **отсутствует поле статуса**. Все записи — действующие таможенные представители (на дату файла). При исключении из реестра запись, как правило, удаляется из источника.
- Исходный файл имеет структуру **1:N** (одна организация = несколько строк по подразделениям). Справочник агрегирует их в одну карточку, собирая подразделения в единый список.
- Все элементы интерфейса (бейджи, вложенные списки) добавлены на стороне справочника для удобства пользователей и не являются частью официального источника.
